# Data

This project uses the **Indian Pines** hyperspectral scene (AVIRIS sensor, 145 x 145 pixels,
200 spectral bands after removal of the water absorption bands, 16 land-cover classes).

Download these two files from the
[Hyperspectral Remote Sensing Scenes](https://ehu.eus/ccwintco/index.php/Hyperspectral_Remote_Sensing_Scenes)
page of the Computational Intelligence Group (University of the Basque Country), and place them in this folder:

- `Indian_pines_corrected.mat` (corrected Indian Pines)
- `Indian_pines_gt.mat` (Indian Pines ground truth)

The `.mat` files are ignored by Git and are not included in this repository.
